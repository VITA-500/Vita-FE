# 채팅 매장 지도 기준점 표시 QA

작성 기준: 채팅 매장 지도에서 질문 의도에 따라 지도 핀을 분리하는 변경

## 테스트 목적

- 장소 기준 매장 검색에서는 검색 기준 장소와 매장 핀만 표시한다.
- 현재 위치 기반 탐색·길찾기에서는 사용자 현재 위치 핀과 매장 핀을 함께 표시한다.
- BE 응답에 `UserOrigin` 별도 필드가 없어도 화면이 정상 동작한다.

## 사전 조건

- 위치 권한을 허용할 수 있는 브라우저 환경
- 위치 권한을 거부할 수 있는 브라우저 환경
- 채팅 응답에 매장 지도 블록이 포함된 계정
- 다음 두 종류의 BE 응답을 준비한다.

### 장소 기준 응답

```json
{
  "storeMap": {
    "origin": { "lat": 37.5401, "lng": 127.0701 },
    "originSource": "place",
    "originLabel": "건대입구역",
    "stores": []
  }
}
```

### 현재 위치 기준 응답

```json
{
  "storeMap": {
    "origin": { "lat": 37.4981, "lng": 127.0276 },
    "originSource": "current",
    "originLabel": null,
    "stores": []
  }
}
```

## 챗봇 직접 질문 시나리오

아래 문장을 채팅 입력창에 그대로 입력해 확인한다. 질문 전후의 위치 권한 상태와 지도 핀을 함께 확인한다.

| ID    | 상황                                   | 입력 예시                                                                  | 기대 결과                                                                                                            |
| ----- | -------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| OM-01 | 역 근처 매장 검색                      | `건대입구역 근처 매장 보여줘`                                              | 건대입구역 주변 매장이 표시된다. 지도에는 매장 핀만 표시되고 사용자 현재 위치 핀은 표시되지 않는다.                  |
| OM-02 | 다른 장소 근처 검색                    | `강남역 근처 제휴 카페 찾아줘`                                             | 강남역 기준 제휴 카페 매장이 표시된다. 장소 기준 핀이 별도로 표시되지 않는다.                                        |
| OM-03 | 장소 기준 거리 확인                    | `왕십리역 근처 매장 알려줘`                                                | 매장 카드의 거리가 `왕십리역에서 약 N m` 또는 `왕십리역에서 약 N km`로 표시된다.                                     |
| OM-04 | 장소 검색 후 내 위치 확인              | OM-01 응답 후 지도에서 내 위치 버튼 클릭                                   | 위치 권한 허용 시 사용자 위치 핀이 추가된다. 기존 장소 기준 매장 목록은 유지된다.                                    |
| OM-05 | 내 주변 매장 검색                      | `내 주변 매장 찾아줘`                                                      | 현재 위치 주변 매장이 표시되고 사용자 위치 핀과 매장 핀이 함께 표시된다.                                             |
| OM-06 | 현재 위치 기준 거리 확인               | `내 위치에서 가까운 VITA 매장 알려줘`                                      | 사용자 위치 기준 매장 순서와 거리가 표시된다. 사용자 위치 핀과 매장 핀이 함께 표시된다.                              |
| OM-07 | 특정 매장까지 길찾기                   | `내 위치에서 VITA 강남역점까지 얼마나 걸려?`                               | 해당 매장 중심으로 응답하고 사용자 위치를 출발점으로 사용한다. 지도에는 사용자 위치 핀과 해당 매장 핀이 표시된다.    |
| OM-08 | 특정 매장 위치 탐색                    | `VITA 강남역점 위치 알려주고 길찾기 해줘`                                  | 특정 매장 위치와 길찾기 UI가 표시된다. 사용자 위치를 허용한 경우 사용자 위치 핀도 표시된다.                          |
| OM-09 | 위치 권한 거부 상태에서 내 주변 검색   | `내 주변 매장 찾아줘` 입력 후 위치 권한 거부                               | 위치 오류 안내가 표시되고 사용자 위치 핀은 표시되지 않는다. 화면이 깨지지 않는다.                                    |
| OM-10 | 위치 권한 허용 상태에서 장소 검색      | 위치 권한 허용 후 `건대입구역 근처 매장 보여줘`                            | 장소 기준 매장이 표시되며, 장소 검색 결과에는 사용자 위치 핀을 자동으로 추가하지 않는다.                             |
| OM-11 | 장소+현재 위치 지도에서 매장 카드 선택 | `내 위치에서 건대입구역 근처 매장까지 얼마나 걸려?` 입력 후 매장 카드 클릭 | 선택한 매장 핀으로 포커스가 이동하고 해당 매장 중심으로 확대된다. 장소 전체와 사용자 위치 fit은 일시적으로 해제된다. |
| OM-12 | 매장 포커스 후 전체 기준 복귀          | OM-11 상태에서 지도 내 위치 버튼 클릭                                      | 선택한 매장만 확대된 상태가 해제되고 장소 기준 매장 핀들과 사용자 위치 핀이 다시 함께 보인다.                        |

## 회귀 시나리오

| ID    | 상황                           | 기대 결과                                                                                              |
| ----- | ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| RG-01 | 매장 카드 클릭                 | 선택한 매장으로 지도와 카드 레일이 이동한다.                                                           |
| RG-02 | 매장 핀 클릭                   | 해당 매장이 선택되고 카드 레일이 해당 카드로 이동한다.                                                 |
| RG-03 | 서비스 필터가 포함된 매장 지도 | 서비스 일치 매장 강조와 색상 규칙이 기존과 동일하다.                                                   |
| RG-04 | 매장 목록이 비어 있음          | 빈 지도 블록을 렌더링하지 않는다.                                                                      |
| RG-05 | 장소 기준에서 카드 거리 hover  | 장소 기준 거리를 기본으로 표시하고, 현재 위치를 확보한 경우 hover 시 사용자 위치 기준 거리를 표시한다. |
| RG-06 | 기존 저장 메시지 열기          | 기존 `originSource` 값이 있는 저장 메시지가 오류 없이 표시된다.                                        |

## API/개발자 도구 확인

- Network에서 채팅 응답의 `storeMap`에 `UserOrigin` 필드가 없는지 확인한다.
- `originSource: "place"`인 응답에서 사용자 위치 핀용 좌표를 별도로 생성하지 않는지 확인한다.
- `originSource: "current"`인 응답에서 `origin`이 사용자 위치로 사용되는지 확인한다.
- 장소 기준 검색 시 불필요한 추가 위치 조회 요청이 발생하지 않는지 확인한다.
- 내 위치 버튼 또는 길찾기 진입 시에만 브라우저 위치 권한 요청이 발생하는지 확인한다.
- 각 질문의 답변에 표시된 장소명·매장명·거리 문구가 질문 의도와 일치하는지 확인한다.

## 완료 기준

- 챗봇 직접 질문 시나리오 OM-01~OM-12 통과
- 회귀 시나리오 RG-01~RG-06 통과
- `UserOrigin` 미포함 응답에서 런타임 오류 없음
- 데스크톱과 모바일 화면에서 지도 핀·카드·거리 문구가 정상 표시됨
