# Vita

AI 통신 상담 지원 플랫폼의 프론트엔드입니다.

## 기술 스택

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- next-themes
- motion

## 프로젝트 구조

```text
src
├─ app                  # 앱 라우트와 전역 레이아웃
├─ common               # 공통 UI/모션 컴포넌트
├─ components           # 레이아웃 및 홈 화면 컴포넌트
└─ constants            # 화면 문구
```
